TRẮC NGHIỆM DOCKER
	Câu 1: Docker là gì?
a) Một hệ điều hành độc lập
b) Một nền tảng ảo hóa máy chủ
c) Một nền tảng cung cấp container hóa để phát triển, vận hành và phân phối ứng dụng
d) Một công cụ quản lý mã nguồn
Đáp án: c) Một nền tảng cung cấp container hóa để phát triển, vận hành và phân phối ứng dụng
Câu 2: Lệnh nào dùng để khởi động một container trong Docker?
a) docker start
b) docker launch
c) docker run
d) docker execute
Đáp án: c) docker run
Câu 3: File nào được sử dụng để định nghĩa các bước xây dựng một Docker Image?
a) DockerCompose.yml
b) Dockerfile
c) DockerImage.yaml
d) Containerfile
Đáp án: b) Dockerfile
Câu 4: Lệnh nào dùng để liệt kê tất cả các container đang chạy?
a) docker ps -a
b) docker ps
c) docker list
d) docker show
Đáp án: b) docker ps
Câu 5: Docker Compose được sử dụng để làm gì?
a) Quản lý mạng trong Docker

c) Tạo container mới từ một image
d) Biên dịch Docker Image

Câu 6: Lệnh nào để xóa một container đã dừng?
a) docker delete
b) docker rm
c) docker stop
d) docker rmi

Câu 7: Lệnh nào được sử dụng để xóa một Docker Image?
a) docker remove image
b) docker delete image
c) docker rmi
d) docker rm image

a) Một công cụ để tạo Docker Image
